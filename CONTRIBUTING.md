# Contributing

Thank you for helping improve Cardiff Bin Collections.

By submitting a contribution, you confirm that it is your original work or that
you have the right to submit it under the MIT licence. Do not copy code from
other Cardiff waste integrations. Public API facts, independently observed
request/response shapes, and links to public documentation may be documented.

Please redact residential addresses, postcodes, UPRNs, verification tokens, and
Home Assistant secrets from issues, logs, fixtures, and screenshots.

Run `pytest` and `ruff check .` before opening a pull request.
